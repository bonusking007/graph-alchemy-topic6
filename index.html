1) Directed Graph คืออะไร?

Directed graph หรือ digraph ประกอบด้วยจุดยอด V และเส้นเชื่อมมีทิศทาง E เช่น A → B ไม่เท่ากับ B → A

G = (V, E)
V = {A, B, C}
E = {(A,B), (B,C)}

ในโปรเจกต์นี้กำหนดให้ ไม่มี self-loop ดังนั้นจุดยอดหนึ่งจุดจะไม่ชี้กลับเข้าหาตัวเอง

2) Graph Isomorphism คือหัวใจของ Topic 6

กราฟ G และ H เป็น isomorphic กัน เมื่อมี bijection f ระหว่างจุดยอด และทุก directed edge ถูกเก็บรักษาไว้ภายใต้การเปลี่ยนชื่อจุดยอด

(u → v) อยู่ใน G ⇔ (f(u) → f(v)) อยู่ใน H

ตำแหน่งที่วาด สี และชื่อจุดยอดไม่ใช่โครงสร้าง สิ่งสำคัญคือรูปแบบการเชื่อมต่อและทิศทางของลูกศร

3) Invariant ใช้คัดกรอง แต่ไม่ใช่หลักฐานเสมอไป

  • จำนวน edges ต้องเท่ากัน ถ้าจะเป็น isomorphic
  • ชุดค่า in-degree / out-degree ต้องสอดคล้องกัน
  • จำนวน mutual pairs หรือ cycle บางชนิดช่วยแยกกราฟได้
⚠️ ถ้า invariant บางตัว “เหมือนกัน” ยังสรุปไม่ได้ว่ากราฟ isomorphic ต้องตรวจ bijection หรือ canonical form ต่อ

4) Full Set หมายถึงอะไร?

เริ่มจาก labelled digraphs ทุกแบบ แล้วรวมกราฟที่ isomorphic กันไว้ในคลาสเดียว จากนั้นเลือกตัวแทนเพียงหนึ่งกราฟต่อคลาส

n = 2: labelled 4 แบบ → nonisomorphic 3 แบบ
n = 3: labelled 64 แบบ → nonisomorphic 16 แบบ
n = 4: labelled 4,096 แบบ → nonisomorphic 218 แบบ

ตัวอย่างเร็ว: หน้าตาต่าง แต่โครงสร้างเดียวกัน

Graph G: A → B
≅
Graph H: 1 → 2
Bijection ตัวอย่าง: f(A)=1, f(B)=2 ⇒ edge A→B ถูกส่งไปเป็น 1→2 จึงเป็น isomorphic

Canonical Form ที่ระบบใช้

สำหรับกราฟที่มี n จุดยอด ระบบลองสลับชื่อจุดยอดทุก permutation จำนวน n! แบบ แล้วเข้ารหัส adjacency เป็น bit mask จากนั้นเลือกค่าที่เล็กที่สุดเป็น canonical representative

canonical(G) = min { encode(π(G)) : π เป็น permutation ของ V }
G ≅ H ⇔ canonical(G) = canonical(H)
⏱️ วิธีนี้ถูกต้องสำหรับ n เล็ก แต่จำนวนงานโตเร็วประมาณ 2^(n(n−1)) × n! จึงตั้งใจจำกัด Live Generator ไว้ที่ n ≤ 4 ในเวอร์ชันสาธิต
