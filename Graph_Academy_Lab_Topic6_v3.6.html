1) Directed Graph คืออะไร?

Directed graph หรือ digraph ประกอบด้วยจุดยอด V และเส้นเชื่อมมีทิศทาง E เช่น A → B ไม่เท่ากับ B → A

G = (V, E)
V = {A, B, C}
E = {(A,B), (B,C)}

ในโปรเจกต์นี้กำหนดให้ ไม่มี self-loop ดังนั้นจุดยอดหนึ่งจุดจะไม่ชี้กลับเข้าหาตัวเอง

2) Isomorphic และ Non-Isomorphic ต่างกันอย่างไร?

Isomorphic หมายถึงกราฟ 2 รูปที่อาจวาดต่างตำแหน่งหรือใช้ชื่อจุดยอดต่างกัน แต่จริง ๆ มีโครงสร้างเดียวกัน เพราะสามารถจับคู่จุดยอดแบบ bijection แล้วรักษาทิศทางของทุก directed edge ได้

G ≅ H เมื่อมี bijection f ที่ทำให้
(u → v) อยู่ใน G ⇔ (f(u) → f(v)) อยู่ใน H

Non-Isomorphic หมายถึง ไม่มี การจับคู่จุดยอดแบบใดที่ทำให้โครงสร้างและทิศทางของลูกศรตรงกันทั้งหมด ดังนั้นกราฟเหล่านั้นถือเป็น “คนละโครงสร้าง” และต้องเก็บไว้เป็นคนละสมาชิกของ Full Set

✓ Isomorphic
เปลี่ยนชื่อ/ตำแหน่งได้ แต่ adjacency และทิศทางยังตรงกันหลัง relabel
✕ Non-Isomorphic
ไม่มี bijection ใดรักษา directed edges ได้ครบ จึงเป็นโครงสร้างใหม่อีกคลาสหนึ่ง

3) Invariant ใช้คัดกรอง แต่ไม่ใช่หลักฐานเสมอไป

  • จำนวน edges ต้องเท่ากัน ถ้าจะเป็น isomorphic
  • ชุดค่า in-degree / out-degree ต้องสอดคล้องกัน
  • จำนวน mutual pairs หรือ cycle บางชนิดช่วยแยกกราฟได้
⚠️ ถ้า invariant บางตัว “เหมือนกัน” ยังสรุปไม่ได้ว่ากราฟ isomorphic ต้องตรวจ bijection หรือ canonical form ต่อ

4) Full Set of Nonisomorphic Directed Graphs คืออะไร?

นี่คือ เป้าหมายหลักของ Topic 6: สร้าง labelled directed graphs ทุกแบบ แล้วใช้ isomorphism เพื่อตรวจว่ารูปใดเป็นโครงสร้างซ้ำ จากนั้นเก็บ ตัวแทนเพียง 1 กราฟต่อ 1 non-isomorphic class

Generate all labelled digraphs
↓
Group isomorphic graphs together
↓
Keep 1 representative from each class = Full Set

ตัวอย่าง n = 2 แบบไม่มี self-loop: labelled graph มี 4 แบบ แต่ A→B และ B→A isomorphic กันเพราะสลับชื่อ A,B ได้ จึงเหลือ Full Set เพียง 3 โครงสร้าง: ไม่มีลูกศร / ลูกศรทางเดียว / ลูกศรสวนกันสองทิศ

n = 2: 4 labelled → 3 non-isomorphic
n = 3: 64 labelled → 16 non-isomorphic
n = 4: 4,096 labelled → 218 non-isomorphic

ตัวอย่างตารางจำนวนกราฟ

เมื่อจำนวนจุดยอดเพิ่มขึ้น จํานวน labelled directed graphs จะเพิ่มเร็วมาก แต่หลังจัดกลุ่มกราฟที่ Isomorphic กัน จะเหลือเฉพาะโครงสร้างที่ไม่ซ้ำกันจริง

จำนวนจุดยอด (n) เส้นเชื่อมสูงสุด n(n−1) กราฟทั้งหมด 2^(n(n−1)) Non-Isomorphic Classes (Full Set)

เกร็ดความรู้: Canonical Form เกี่ยวกับ Topic 6 อย่างไร?

Canonical Form ใช้สร้างตัวแทนมาตรฐานของกราฟหนึ่งโครงสร้าง โดยลองเปลี่ยนชื่อจุดยอดหลายแบบแล้วเลือกรูปแบบมาตรฐานเดียวกัน หากกราฟสองรูปได้ Canonical Form เดียวกัน แสดงว่า Isomorphic กันและควรนับเป็น Class เดียว ไม่เพิ่มซ้ำใน Full Set

แล้ว Complexity มีไว้ทำไม? จำนวนกราฟและ permutation โตเร็วมาก จึงช่วยอธิบายว่าทำไมโหมด Interactive ของเว็บจึงจำกัดไว้ที่ n ≤ 4 แนวคิดสองส่วนนี้สามารถใช้ร่วมกันในการ จัดกลุ่มและลดโครงสร้างเครือข่ายที่ซ้ำกัน เช่น network topology, workflow/state model และรูปแบบการเชื่อมโยงข้อมูล ก่อนนำไปวิเคราะห์ต่อ

ตัวอย่างเร็ว: หน้าตาต่าง แต่โครงสร้างเดียวกัน

Graph G: A → B
≅
Graph H: 1 → 2
Bijection ตัวอย่าง: f(A)=1, f(B)=2 ⇒ edge A→B ถูกส่งไปเป็น 1→2 จึงเป็น isomorphic

📖 User Manual — Graph Lab

คู่มือสั้น ๆ สำหรับทดลองสร้าง Directed Graph และตรวจว่าอยู่ใน Nonisomorphic Class ใด ใช้เพียงไม่กี่ขั้นตอน

1

เลือกจำนวนจุดยอด

เลือก n = 2, 3, 4 หรือ 5 จากช่อง จำนวนจุดยอด ระบบจะแสดงจำนวน Class ที่เป็นไปได้ของแต่ละค่า n

2

สร้าง Directed Edge

คลิกจุดยอดต้นทางก่อน แล้วคลิกจุดยอดปลายทาง ระบบจะสร้างลูกศร u → v ให้ทันที หากต้องการลบเส้นให้คลิกที่เส้นนั้น หรือกด ล้างเส้น

3

วิเคราะห์กราฟ

เมื่อสร้างกราฟเสร็จ กด วิเคราะห์กราฟ ระบบจะหา Canonical Form และตรวจว่ากราฟตรงกับ Nonisomorphic Class ใด

4

อ่านผลลัพธ์

โครงสร้างใหม่ หมายถึงยังไม่เคยค้นพบ Class นี้ ส่วน Isomorphic duplicate หมายถึงกราฟหน้าตาอาจต่างกัน แต่มีโครงสร้างเดียวกับ Class ที่มีอยู่แล้ว

5

ดู Collection และใช้ตัวกรอง

ด้านขวาจะแสดง Full Set Collection พร้อมความคืบหน้า และสามารถกรองตามจำนวนเส้นเชื่อมเพื่อหากราฟที่ต้องการได้ง่ายขึ้น สำหรับ n = 5 ระบบจะแบ่ง Collection เป็นหลายหน้าเพื่อให้เว็บทำงานลื่น

6

คำสั่งช่วย

ใช้ คำใบ้ เมื่อต้องการตัวอย่างโครงสร้าง, แสดง Full Set ทั้งหมด เพื่อดูคำตอบครบทุก Class และ รีเซ็ตความคืบหน้า เพื่อเริ่มเก็บ Collection ใหม่

จำง่าย ๆ: เลือก n → วาดลูกศร → วิเคราะห์กราฟ → ดูว่าเป็น Class ใหม่หรือ Isomorphic Duplicate → เก็บให้ครบ Full Set
ทุกระดับสุ่มจำนวนจุดยอด n = 1–5 พร้อมสุ่ม labels, edges และทิศทางใหม่ในแต่ละข้อ · n=1 เป็นกรณีพื้นฐานของ loopless digraph จึงมีโครงสร้างเดียว
